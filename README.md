# Smart X Trucks
## Logistical Management System
<br />
Youtube : https://youtu.be/ndCsIYxb7mU
<br />
<h3>SmartX is a Blazor WebAssembly and ASP.NET Core platform built for real-time fleet telemetry tracking, hardware payload management, and geospatial vehicle routing across logistics networks.</h3>
<br /> 
<br /> 
<h2>Set up Instructions</h2> 
Run:
<br /> dotnet build SmartX.sln to compile solution
<br /> 
<br /> 
Run: 
<br /> dotnet build SmartX.sln to restore dependencies
<br /> 
<br /> 
<h3>Startup</h3>
Under configure startup projects, choose Multiple startup projects and choose SmartX.Server and SmartXClient to Start
<br />
